# Turbulent smooth pipe: set-up

Task w3-internal, Part B (owner decisions I1-I5). The case is built by code (tests/validation/pipe_case.py) through
the app's workflow layer and run by scripts/validation/pipe_study.py (Generate Mesh then Run Solver, as the GUI);
the projects live in run/validation/pipe/ (git-ignored); the numbers go to result.json and RESULT.md.

## References (read on 2026-10-22)

- Prandtl-Karman smooth-pipe law, 1 / sqrt(f) = 2.0 log10(Re sqrt(f)) - 0.8 (Schlichting, Boundary-Layer Theory,
  7th ed., 1979): f = 0.017993 at Re = 1.0e5. Colebrook-White without roughness, 1 / sqrt(f) = -2.0 log10(2.51 /
  (Re sqrt(f))): f = 0.017990. The verdict uses Prandtl-Karman (`pipe_case.prandtl_karman`).
- McKeon, B.J., Swanson, C.J., Zagarola, M.V., Donnelly, R.J. & Smits, A.J. 2004 "Friction factors for smooth pipe
  flow", J. Fluid Mech. 511, 41-44, doi:10.1017/S0022112004009796 (full text from
  https://authors.library.caltech.edu/records/qg80n-a5n38). Its equation (1), 1 / lambda^(1/2) = 1.930 log(Re
  lambda^(1/2)) - 0.537, is stated "for Re_D > 300 x 10^3", so it is not used at Re = 1e5. Its Table 1 gives
  measured friction factors near Re = 1e5: Princeton 9.846e4: 1.815e-2, 1.456e5: 1.666e-2; Oregon 8.476e4:
  1.805e-2, 1.200e5: 1.686e-2 (a cross-check only).
