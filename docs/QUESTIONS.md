## Review round on Task 5.1 (cell budget, layers, staleness)

15. **[DECIDED: moved to D-031.]** **`estimate_mesh` takes the domain bounds and L**, not a `DomainBox`: `foam/` must not import `geometry/` (which imports pyvista), so the box fields are passed as plain data. 17. **[DECIDED: moved to D-042.]** **Background cell limit** is 2,000,000 (`MAX_BACKGROUND_CELLS`): Generate Mesh is disabled with a tooltip above it; the Mesh properties show the cells in warning colour.
18. **[DECIDED: moved to D-032.]** **Layer coverage basis.** snappyHexMesh prints no per-patch count of faces that received layers, so the per-patch coverage is the achieved fraction of the target layer *thickness* (the column "[%]" of its final table) and the report says so (`basis = "thickness"`). The overall share of extruded faces (from the last "Extruding N out of M faces" line) is shown separately. Coverage below 80 % is a warning (colour and console WARNING).
19. **[DECIDED: moved to D-033.]** **Out-of-date mesh** is shown as a separate badge ("Mesh out of date") next to the Saved/Modified badge (so the file state is not hidden), in the Mesh properties (Status row) and as a VTK text in the Mesh Scene. The hash covers part names, units, part file *contents*, the domain and the mesh settings; it ignores the project name, view settings and layer-coverage threshold. A mesh found at project open is shown even if its case/polyMesh was deleted (the report is kept, the viewer logs the load error).
20. **[DECIDED: moved to D-028.]** **Patch names** use the first free numeric suffix (`_1`, `_2`, ...), also against the domain boundary names; the Part properties show the patch name read-only.
