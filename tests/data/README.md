# Test Data Fixtures

## `cavity_icoFoam.log`
Log generated by running `icoFoam` on the standard OpenFOAM cavity reference case (ESI OpenFOAM v2606) using:
```python
params = CavityParams()  # defaults: nu=0.01, delta_t=0.005, end_time=0.5
case = Path(tmpdir) / "cavity"
write_case(case, build_cavity_files(params))
run_foam(["blockMesh"], case_dir=case, log_file=case / "log.blockMesh")
run_foam(["icoFoam"], case_dir=case, log_file=case / "log.icoFoam")
```
The solver ran from `Time = 0.005` to `Time = 0.5` (100 time steps) and completed normally with `End`.

## `cavity_diverged_icoFoam.log`
Real log of a deliberately diverging `icoFoam` cavity run (ESI OpenFOAM v2606), produced with `FoamRun` (no clean stop, `timeout_s=60`, first attempt):
```python
params = CavityParams(delta_t=0.5, lid_velocity=100.0, nu=0.01, end_time=50.0, write_interval=1000)  # 20x20 cells
```
(`end_time = 100 * delta_t`.) `Time = 0.5` completes, then `Time = 1` prints a Courant number of mean 1869.7 / max 6677.83 and the solver dies in `symGaussSeidelSmoother::smooth` with a floating point exception. The log has **no `nan`/`inf` residuals** (OpenFOAM's `FOAM_SIGFPE` traps the first invalid operation) and **no `End`**; the abnormal end is the `[stack trace]` ... `=============` block (parsed as `SolverCrash`). Process exit code: **-8** (`RunResult.exit_code`, killed by SIGFPE); `timed_out` was False after 0.65 s.
